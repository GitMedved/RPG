# Mia & Max — CC0 3D asset and dialogue integration

This file describes exactly what is installed in Git, what will be used at runtime,
and which optional steps are still required before considering assets final.

## 1. Real 3D models already committed to Git

**8 Gobkit nature GLBs**, sourced from [Ariescar/gobkit-free-assets](https://github.com/Ariescar/gobkit-free-assets),
licensed **CC0 1.0** (the original LICENSE is committed alongside the assets):

- `Assets/Resources/MiaMax/External/Gobkit/{TreeHigh001,TreeLow003}.glb`
- `{Bush001,Bush002}.glb`
- `{Rock001,Rock002}.glb`
- `{Grass001,Reed001}.glb`

These files contain *real* imported 3D meshes rather than primitive objects.
`MiaMaxExternalArtPass.AddNature` instantiates them in the active backyard.
When Unity cannot import a GLB, the previous illustrated art remains visible.

**2 CC0 rigged human candidates**, downloaded and committed using GitHub Actions:

- `Assets/Resources/MiaMax/External/Candidates/MiaSchoolkidCandidate.glb`: Gobkit's [free Schoolkid](https://gobkit.com/api/free) model with skin and animation data
- `Assets/Resources/MiaMax/External/Candidates/MiaRogueCandidate.glb`: [KayKit Adventurers](https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0), fully rigged and animated, CC0 1.0

These files are **candidate rigs, not Mia**. They are not a faithful reproduction of the saved original Mia reference. No original likeness is replaced automatically by a visually unrelated character.

## 2. Animated cat model

Official source: [Vuena's free Cute Pets & Wildlife sample](https://vuena.itch.io/blocky-pets-free),
**CC0** for the FREE sample (not the paid full pack).

The free pack includes a cat with opening mouth, blinking eyes, a skinned rig, mobile LOD,
and twelve clips: idle, idle_alt, walk, run, jump, eat, sit, sleep, attack, call, hit, death.
The ZIP is provided behind a name-your-price download page on itch.io; no stable public
binary download URL has been confirmed. We intentionally do **not** bypass the site's checkout.

**Install once in Unity**:

1. On the official page, select **Download Now → No thanks, just take me to the downloads**,
   then download `Cute-Pets-Wildlife-FREE-Sample-CC0-v3.1.zip` (version name may update).
2. In Unity use **Mia & Max → Art Pipeline → 2. Import Free Animated Cat Archive**.
   Select that ZIP. The importer extracts the matching Cat GLB.
3. Select **Mia & Max → Art Pipeline → 3. Build Animated Max Prefab (Review Candidate)**.
   It creates `Resources/MiaMax/External/Cast/MaxRig.prefab` and an AnimatorController
   with Idle / React / Talk states derived from the imported animation clips.
4. Run **Mia & Max → Art Pipeline → 5. Verify Imported Rigs and Animation Clips**.
   After a clean re-enter of Play Mode, the game replaces the Max proxy if the new
   prefab has renderers; otherwise the old proxy remains.

To test a human rig, run
**Mia & Max → Art Pipeline → 4. Build Animated Mia Prefab (Review Candidate)**.
Choose Schoolkid (child-like proportions) or KayKit Rogue (fantasy clothes).
These are only technology and animation candidates. A bespoke reference-faithful
Mia needs a custom art pass and approval before commercial release.

Imported rigs are activated by `MiaMaxRigAnimator.cs`; gameplay sends
React and Speak events, with zero character locomotion and a fixed camera.

## 3. Character voice / cat sounds

**2 actual CC0 meows were committed as OGG files**:
`Assets/Resources/MiaMax/Audio/SFX/max_meow_01.ogg` and `max_meow_02.ogg`.
Source: Joseph Sardin / BigSoundBank, mirrored in
[druboni/find-the-cat](https://github.com/druboni/find-the-cat/blob/main/CREDITS.md).
`GameAudioService` loads these audio files, applies cooldown, and avoids
playing them over character dialogue.

**6 original American-English voice takes generated by HeyGen**:

| Clip ID | Speaker / purpose |
| --- | --- |
| `mia_greeting_01` | Mia introduces the backyard |
| `mia_birdhouse_ready_01` | Mia celebrates the birdhouse |
| `max_birdhouse_01` | Max answers Mia |
| `mia_secret_garden_01` | Mia celebrates opening the garden |
| `max_garden_discovery_01` | Max discovers the golden stone |
| `max_treasure_win_01` | Max celebrates sorting treasure |

Voices: Mia = Cassidy (en-US), Max = Jalen (en-US).

There are two ways to install WAVs:

- **Automated:** `.github/workflows/package-mia-max-voices.yml` downloads and processes
  the originals via FFmpeg (high-pass 85 Hz, low-pass 10 kHz, loudness target -17 LUFS,
  max true peak -1.5 dBTP), then commits the WAVs + meta files into the feature branch.
  Check GitHub Actions; a source-provider failure can prevent the job from succeeding.
- **Local fallback:** Unity menu **Mia & Max → MVP → 4. Install Generated English Voice Takes**
  downloads six WAVs when used outside Play Mode. Commit these WAVs and their generated
  .meta files afterward. The game never streams or downloads speech at runtime.

**No WAVs should be reported as installed unless the actual files exist under**
`Assets/Resources/MiaMax/Audio/Voice/`.

Runtime audio ducks music and ambience while characters speak. This is a preliminary
mixing pass and still requires listening/level QA on devices.

## 4. Verify

1. Pull `codex/mia-max-foundation`.
2. Open with Unity 6000.3.0f1; allow glTFast package imports to complete.
3. Run **Mia & Max → MVP → 1. Preflight Assets & Scene**.
4. Start Play Mode; run **Mia & Max → MVP → 2. Inspect Running World**.
5. Inspect the original-portrait UI, full yard art, imported trees/rocks/grass,
   two character rigs, face movement and all taps.
6. Complete the birdhouse → flowers → keepsake → Secret Garden chapter, listen
   to the voice takes and check the music ducking.
7. Use **Art Pipeline → 5. Verify Imported Rigs and Animation Clips** to check
   skinned meshes and actual clip count.

## 5. Important quality boundary

The exact appearance of Mia and Max in the user-provided reference images
has not been reproduced as a high-fidelity custom rig. The included existing
procedural character models remain the default; third-party rigs are explicitly
reviewed before replacement. Full expressive blendshapes/phoneme lip-sync,
handcrafted clothing/fur, and a Unity/device validation pass remain to be done.
**This is an integration candidate, not a production art acceptance certificate.**
