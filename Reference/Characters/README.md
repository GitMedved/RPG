# Character Reference Images

Place the approved, original character reference images in this folder.

Recommended filenames:
- `Mia.jpg` or `Mia.png`
- `Max.jpg` or `Max.png`

Optional additional views:
- `Mia_Front.png`, `Mia_Side.png`, `Mia_Back.png`, `Mia_Expressions.png`
- `Max_Front.png`, `Max_Side.png`, `Max_Back.png`, `Max_Expressions.png`

Keep original, unedited images here. This folder is at the repository root (outside Unity's `Assets/`) so reference boards and source images are not automatically imported into the game build. Production-ready models, textures and animation exports belong under `Assets/_Project/Art/Characters/`.

Do not replace the approved reference images with generated proxy screenshots. Preserve the original files and their filenames where possible.
